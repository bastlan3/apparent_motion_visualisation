Foster (1975) — preferred paths in the rotation group SO(3)

A bar undergoes apparent motion (rotate + translate) between A and σ(A). In the upper array a probe bar B is inserted; the observer places it so the upper motion A→B→σ(A) matches the lower reference motion A→σ(A).
Fixate an array centre. Adjust the probe bar's vertical position and orientation until the motion in the upper array looks identical (as a path) to the motion in the lower array. Then record.

Faithful reconstruction of the Section 3 experiment in Foster, D. H. (1975), Biol. Cybernetics 18, 81–89. Two vertically stacked arrays (corresponding points 2.7° apart; bars 0.9° long) shown in Maxwellian view. Lower array = reference beta motion A ⇄ σ(A); upper array = A → B → σ(A) with an adjustable probe bar B. The observer fixes the probe's vertical position (θ₁ρ) and orientation (θ₃ρ) — the experimenter fixes its horizontal position (θ₂ρ, swept 0→θ₂σ) — so the upper path matches the lower. Coordinates are SO(3) rotations: θ₂ about the vertical axis (horizontal offset), θ₁ about the horizontal axis (vertical offset), θ₃ about the line of sight (in-plane orientation, the large one). A is a vertical bar; σ(A) is displaced + rotated. The smooth beta-motion path is the observer's percept and is deliberately not drawn — only the discrete flashes and the probe appear. Stimulus cycle 2.0 s. (Scheme 1 / Scheme 2 predicted probe placements to be added as an experimenter readout.)
